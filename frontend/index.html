How to use your map:

  • Add: Click "+ Add a dot" in Mind Map Actions (or press N)
  • Select: Click any dot to select it
  • Link: Use "Link dots" to connect related experiences
  • Unlink: Open a dot's Connections, or tap the line between two, to remove a link
  • Edit: Select a dot, then click "Edit" to modify it
  • Navigate: Use Tab key to move between dots

    Export & backup

    Encrypted backup. The safe way to keep or move your map. It stays encrypted, so it's fine to store anywhere (a drive, a cloud, a USB stick).

    Because Wymber is open-source, a .wymber file is always yours to open. Even if this site disappeared, the code is public, so your data is never locked away.

    Unencrypted copies for your own reading. Anyone who gets these files can read them, so keep them somewhere private.

    You're not alone

    If you're in crisis or thinking about harming yourself, please reach out. Help is available right now, and you deserve it.

    • 988 Suicide & Crisis Lifeline (US) Reach a counselor any time, day or night. Free and confidential. Call 988 Text 988
    • Crisis Text Line Text-based support, if talking is too much right now. Text HOME to 741741
    • 911 Emergency services (US). Call 911
    • Find a helpline in your country 175+ countries (needs internet).
