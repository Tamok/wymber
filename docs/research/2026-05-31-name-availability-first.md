# Name — Availability-First Round

**Date:** 2026-05-31 · After 3 deep-verification failures (Mendmap CAUTION, Calluna CAUTION, Velora NO-GO), this round **inverted the method**: pre-screen app-store + `.com` + GitHub org + trademark for each coined candidate BEFORE proposing, and only surface names that pass all four gates.

> Web-inferred (May 2026 index, Jan 2026 cutoff). Not legal advice / not a clearance opinion — survivors are *candidates to formally clear*, not cleared. App-store/registrar/TM states change daily.

## Headline finding
**This space is a graveyard for short, pretty, pronounceable names.** Of ~30 coined candidates checked, the large majority collided — and almost every collision was a *live mental-health/wellness app* with a near-identical name (Looma, Embra, Nooma, Soomi, Pebbl, Tovi, Klyne, Nuvio, Nestra, Steddy, Kalmu, Soluna, Knotly, Untangle…). This confirms the Velora/Calluna/Mendmap lesson: **the prettier/more "wellness-sounding" the token, the more certainly it's taken.** The survivors are the *odd/harder/less-pretty* ones — the Wysa/Woebot/Daylio pattern. **Only 2 clean (+1 weak) survived all four gates — that under-supply is itself the signal:** expect to go weirder than instinct wants, or brief a professional namer + lawyer for a formal coined-name sprint.

## Survivors (passed app-store + .com + GitHub + TM gates)

### 1. Wymber — **top pick**
Soft, warm, slightly old-worldly; the "-mber" ending (ember/amber/timber) carries quiet warmth + resilience without naming an emotion. Easy to say + spell-on-hearing, no negative meaning, distinctive in the Wysa/Daylio register.
- **Gates:** app stores clean; `wymber.com` parkable; `github.com/wymber` free; no conflicting TM/company found.
- **Only flag:** a *defunct* wellness app "Wymbe" (out of business 2023) is a near-homophone — low risk, note it.
- **Handles:** wymber.com (verify) / wymber.app / getwymber.com; GitHub org free.
- **Taglines:** "Map your way through trauma — privately, at your own pace." · "Hold your story together. A calm, private map of trauma and healing."

### 2. Zevuli — clean alternative
Fully invented, **zero collisions on any gate** (cleanest availability profile in the set). Bouncy, memorable, ownable (Daylio/Sanvello energy). Trade-off: opaque meaning + "Zev-" start is slightly less intuitive to spell on first hearing.
- **Gates:** all pass; zevuli.com parkable; `github.com/zevuli` free; @zevuli appears open.
- **Taglines:** "Your private map for making sense of trauma." · "Untangle trauma into a map you control — calm, encrypted, yours."

### 3. Quolm — passes gates but **weak (do not lead)**
Passes all four availability gates, **but fails tone/brandability**: homophone of "qualm" (a pang of unease) — wrong emotional charge for a calming product — and harsh/hard to spell. Listed for completeness only.

**Honorable mention — Tovel:** app stores clean and only collides with *industrial* manufacturers (different TM class), sounds calm/human — **but** `.com` is held and `github.com/tovel` is taken. Viable only with `tovel.app`/`tovelhealth.com` + a different org slug.

## Recommendation
**Wymber** is the strongest candidate found across all rounds — it cleared the exact gates (live mental-health app collision, .com, GitHub, TM) that killed Mendmap/Calluna/Velora. Adopt it **provisionally** and do the formal pre-commit checks below before any spend/launch. Zevuli is the safe fallback if Wymber stumbles on formal clearance.

## Verify-at-official-source (before committing/spend)
1. **USPTO TESS** — exact + phonetic in Class 9 (apps) + 44 (wellness); for Wymber also "Wymbe"/"Wimber"/"Wymberg". **EUIPO + WIPO** for international.
2. **Registrar WHOIS** (not inference) — confirm `.com` actually registrable for Wymber/Zevuli; price `.app`/`.health`/`.co`.
3. **App Store Connect + Play Console** — attempt the name reservation (authoritative; web search isn't). Manually search Health/Lifestyle/Medical.
4. **Reserve handles + GitHub org** in one sitting (X/IG/TikTok/Reddit) to avoid split-brand.
5. **Say-it-aloud test** with 3–5 people (spell it cold) to catch homophone traps.
6. **Trademark counsel** clearance opinion before public launch.
